基础信息

  • Base URL（开发）：http://localhost:8080/api/v1
  • Base URL（生产）：http://localhost/api/v1（Nginx 反向代理）
  • 认证方式：Authorization: Bearer <token>
  • 数据格式：JSON

公开接口（无需认证）

获取文章列表

GET /api/v1/posts?page=1&size=10

返回分页文章列表，content 字段为 null（节省流量）。

获取文章详情

GET /api/v1/posts/{id}

返回完整文章内容（含 Markdown 正文）。

搜索文章

GET /api/v1/posts/search?q={keyword}

基于 PostgreSQL tsvector 全文搜索。

获取标签列表

GET /api/v1/tags

按标签获取文章

GET /api/v1/tags/{slug}/posts

获取文章评论

GET /api/v1/posts/{id}/comments

认证接口

用户注册

POST /api/v1/auth/register
Content-Type: application/json

{
  "username": "newuser",
  "email": "user@example.com",
  "password": "password123"
}

用户登录

POST /api/v1/auth/login
Content-Type: application/json

{
  "email": "admin@example.com",
  "password": "admin123"
}

返回：

{
  "token": "<jwt-token>"
}

需要认证的接口

发表评论

POST /api/v1/comments
Authorization: Bearer <token>
Content-Type: application/json

{
  "postId": 1,
  "content": "评论内容"
}

管理员接口（需要 ADMIN 角色）

创建文章

POST /api/v1/admin/posts
Authorization: Bearer <token>
Content-Type: application/json

{
  "title": "文章标题",
  "slug": "article-slug",
  "summary": "文章摘要",
  "content": "# Markdown 内容",
  "coverImageUrl": "https://example.com/image.jpg",
  "published": true,
  "tags": ["kotlin", "backend"]
}

更新文章

PUT /api/v1/admin/posts/{id}
Authorization: Bearer <token>
Content-Type: application/json

{
  "title": "更新后的标题",
  "content": "更新后的内容",
  "published": true
}

删除文章

DELETE /api/v1/admin/posts/{id}
Authorization: Bearer <token>

获取用户列表

GET /api/v1/admin/users
Authorization: Bearer <token>

更新用户角色

PUT /api/v1/admin/users/{id}/role
Authorization: Bearer <token>
Content-Type: application/json

{
  "role": "ADMIN"
}

可用角色：USER（默认）、ADMIN

快速测试（curl）

TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"admin123"}' \
  | grep -o '"token":"[^"]*"' | cut -d'"' -f4)

curl http://localhost:8080/api/v1/posts

curl -X POST http://localhost:8080/api/v1/admin/posts \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"title":"测试文章","content":"内容","published":true}'

也可直接运行 ./test-api.sh 执行完整测试套件。
