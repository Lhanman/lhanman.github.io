技术栈

  • Kotlin Multiplatform — 跨平台代码共享
  • Compose Multiplatform — 声明式 UI
  • Ktor Client — 网络请求（OkHttp / Darwin / JS / CIO 引擎）
  • Coil 3 — 图片加载
  • Navigation Compose — 路由导航
  • Multiplatform Settings — 本地存储（Token 持久化）
  • kotlinx-coroutines-swing — Desktop 主线程调度器（解决 Dispatchers.Main 缺失）

MVVM 数据流

BlogListScreen (Composable UI)
    │ collectAsState()
    ↓
BlogListViewModel
    │ state: StateFlow<BlogListState>
    │ postRepository.getPosts(page, size)
    ↓
PostRepository (interface)
    │ 实现类
    ↓
PostRemoteDataSource
    │ client.get("/api/v1/posts")
    ↓
ApiClient (Ktor HttpClient)
    │ 自动附加 Authorization: Bearer <token>
    ↓
Backend: GET /api/v1/posts?page=1&size=10

跨平台适配：expect/actual 机制

// commonMain — 声明
expect fun isSystemInDarkMode(): Boolean

// androidMain / desktopMain / macosMain — 实现
actual fun isSystemInDarkMode(): Boolean = isSystemInDarkTheme()

// wasmJsMain — 实现
actual fun isSystemInDarkMode(): Boolean = false

Desktop 支持说明

  • frontend/composeApp/build.gradle.kts 已新增 jvm("desktop")
  • desktopMain 依赖已接入 compose.desktop.currentOs 与 ktor-client-cio
  • 桌面打包已启用：Dmg / Msi / Exe
  • ViewModel 使用 viewModelScope 时，Desktop 端必须带 kotlinx-coroutines-swing

前端编译注意事项

  • inline 函数不能访问 private 或 internal 属性，需使用 public
  • expect/actual 函数的注解必须完全匹配（包括 @Composable）
  • PagedResponse 使用 page 字段而不是 currentPage
  • Tag 对象需使用 tag.name 而不是直接使用 tag
  • 桌面安装包通常应在对应操作系统上生成（例如 Windows 安装包建议在 Windows 上打包）
