技术栈

  • Kotlin + Ktor Server — RESTful API
  • PostgreSQL — 数据库
  • Exposed ORM — 数据库访问（DSL 参数化查询，防 SQL 注入）
  • JWT (HS256) — 身份认证，有效期 7 天
  • BCrypt (cost=10) — 密码加密
  • Flyway — 数据库迁移
  • HikariCP — 连接池

启动流程

// Application.kt
fun Application.module() {
    DatabaseFactory.init(dbUrl, dbUser, dbPassword)  // 1. 初始化数据库连接池
    configurePlugins()   // 2. CORS, ContentNegotiation(JSON), StatusPages
    configureAuth()      // 3. JWT 认证配置
    routing {            // 4. 注册路由
        postRoutes(postRepository)
        tagRoutes(tagRepository)
        authRoutes(userRepository)
        commentRoutes(commentRepository)
        adminRoutes(postRepository, tagRepository, userRepository)
    }
}

安全机制

  • 密码存储：BCrypt (cost=10)
  • JWT 签名：HMAC-SHA256
  • Token 有效期：7 天
  • SQL 注入防护：Exposed DSL 参数化查询
  • XSS 防护：Compose 天然防御

认证流程

LoginScreen 输入 email + password
    ↓
POST /api/v1/auth/login
    ↓
BCrypt.checkpw(password, user.passwordHash)
    ↓
生成 JWT (有效期 7 天)
    ↓
TokenRepository.saveToken(token)
    ↓
后续所有请求自动附带 Authorization: Bearer <token>
