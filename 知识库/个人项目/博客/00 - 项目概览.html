简介

基于 Kotlin Multiplatform (KMP) + Compose Multiplatform 构建的全栈跨平台个人博客系统。

技术栈

层级技术说明
后端Kotlin + Ktor + PostgreSQL + Exposed ORMJVM 服务端，RESTful API
前端Compose MultiplatformAndroid / iOS / macOS / Windows / Web(WASM)
共享层Kotlin Multiplatform前后端共享 DTO 数据模型
认证JWT (HS256)无状态认证，支持角色权限
数据库PostgreSQL 14+支持全文搜索（GIN 索引）
构建工具Gradle 8.10.2 + AGP 8.6.1Kotlin DSL 配置
部署Docker ComposePostgreSQL + Backend + Nginx

平台支持

平台状态说明
Android✅ 完全支持API 21+
iOS✅ 完全支持iOS 14+
macOS✅ 完全支持原生 macOS target + Desktop JVM
Windows✅ 完全支持Desktop JVM
Web (WASM)✅ 完全支持现代浏览器
Desktop (JVM)✅ 完全支持Windows / Linux / macOS

三模块架构

:composeApp (前端)
    └── depends on
:shared (共享模块)
    └── depends on
:backend (后端)
  • :shared — 定义前后端共享的 DTO，编译到所有目标平台
  • :backend — 纯 JVM 模块，Exposed ORM 与数据库交互
  • :composeApp — Multiplatform 模块，Compose Multiplatform 构建 UI
