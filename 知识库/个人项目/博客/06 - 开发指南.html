Gradle 项目结构

项目包含三个 Gradle 子项目：

项目名物理路径说明
:backendbackend/后端服务
:sharedshared/共享模块
:composeAppfrontend/composeApp/前端应用

注意：虽然前端代码在 frontend/composeApp/ 目录，但 Gradle 项目名是 :composeApp，所有命令都用 :composeApp 而不是 :frontend:composeApp。

常用构建命令

后端

./gradlew :backend:run        # 本地运行（默认端口 9191）
./gradlew :backend:build      # 构建 JAR
./gradlew :backend:test       # 运行测试

前端

# Web 开发模式（访问 http://localhost:8080，接口默认走 http://localhost:9191）
./gradlew :composeApp:wasmJsBrowserDevelopmentRun

# Web 生产构建
./gradlew :composeApp:wasmJsBrowserDistribution

# Android
./gradlew :composeApp:installDebug
./gradlew :composeApp:assembleRelease

# Desktop 运行（macOS / Windows / Linux）
./gradlew :composeApp:run

# 为当前操作系统打包桌面安装产物
./gradlew :composeApp:packageDistributionForCurrentOS

# macOS 安装包
./gradlew :composeApp:packageDmg

# Windows 安装包
./gradlew :composeApp:packageExe
./gradlew :composeApp:packageMsi

# 前端测试
./gradlew :composeApp:test

全量

./gradlew test      # 运行所有测试
./gradlew projects  # 查看所有子项目

桌面端开发说明

  • 当前已接入 jvm("desktop")，生成了真实的 :composeApp:run 桌面任务
  • Desktop source set 为 frontend/composeApp/src/desktopMain/
  • 桌面入口为 frontend/composeApp/src/desktopMain/kotlin/com/personalblog/app/main.kt
  • Windows 安装包建议在 Windows 环境生成；macOS dmg 建议在 macOS 环境生成

依赖仓库配置

项目使用阿里云镜像（适合国内网络），配置在 settings.gradle.kts：

  • Google Maven: https://maven.aliyun.com/repository/google
  • Maven Central: https://maven.aliyun.com/repository/public
  • Gradle Plugin: https://maven.aliyun.com/repository/gradle-plugin

网络良好时可改回官方仓库：

pluginManagement {
    repositories {
        google()
        mavenCentral()
        gradlePluginPortal()
    }
}

依赖版本管理

所有依赖版本统一在 gradle/libs.versions.toml 中管理，使用 libs. 前缀引用。

修改共享数据模型

  1. 在 shared/src/commonMain/kotlin/ 中修改 DTO
  2. 重新构建：./gradlew :shared:build
  3. 前后端自动使用更新后的模型

添加新 API 端点

  1. 在 backend/src/main/kotlin/com/personalblog/backend/routes/ 创建或修改路由文件
  2. 在 Application.kt 的 routing {} 块中注册路由
  3. 需要认证时用 authenticate("jwt-auth") {} 包裹路由

数据库迁移

  1. 在 backend/src/main/resources/db/migration/ 创建 SQL 文件
  2. 命名格式：V{version}__{description}.sql（例如 V2__add_user_avatar.sql）
  3. 重启后端，Flyway 自动执行

跨平台开发

  • 共享代码放在 commonMain
  • 平台特定代码使用 expect/actual：
    • commonMain 声明 expect 函数/类
    • androidMain / desktopMain / iosMain / macosMain / wasmJsMain 实现 actual

常见编译问题

Yarn Lock 更新

./gradlew kotlinUpgradeYarnLock

macOS/iOS 依赖下载失败

只构建后端和 Web：

./gradlew :backend:build :composeApp:wasmJsBrowserDistribution

或在 frontend/composeApp/build.gradle.kts 中临时注释掉 macOS/iOS target。

Desktop 启动崩溃

如果报错包含 Module with the Main dispatcher is missing，说明桌面端缺少主线程调度器，需要确保 desktopMain 已引入 kotlinx-coroutines-swing。
