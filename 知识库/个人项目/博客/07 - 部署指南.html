本地开发环境

./start-dev.sh    # 启动 PostgreSQL + 后端 + Web 前端
./stop-dev.sh     # 停止所有服务
./status.sh       # 查看运行状态

Docker 部署（推荐生产环境）

1. 构建前端静态文件

./gradlew :composeApp:wasmJsBrowserDistribution

2. 配置环境变量

cp .env.example .env
# 编辑 .env，修改数据库密码和 JWT Secret

3. 启动所有服务

docker compose up -d

4. 访问地址

  • 前端：http://localhost
  • 后端 API：http://localhost/api/v1（Nginx 反向代理）
  • 直接访问后端：http://localhost:8080

常用 Docker 命令

docker compose logs -f       # 查看日志
docker compose down          # 停止服务
docker compose ps            # 查看服务状态

服务架构

用户请求
    ↓
Nginx (80/443)
    ├── /          → 前端静态文件 (WASM)
    └── /api/v1    → 后端 Ktor (8080)
                        ↓
                   PostgreSQL (5432)

环境变量说明

变量说明示例
DB_HOST数据库主机db（Docker）/ localhost
DB_PORT数据库端口5432
DB_NAME数据库名personalblog
DB_USER数据库用户postgres
DB_PASSWORD数据库密码自定义强密码
JWT_SECRETJWT 签名密钥随机长字符串
JWT_ISSUERJWT 签发者personal-blog
JWT_AUDIENCEJWT 受众personal-blog-users

手动部署

./gradlew :backend:build
java -jar backend/build/libs/backend-all.jar

前端静态文件由 Nginx 托管。

生产环境注意事项

  • 移除 Android network_security_config.xml 中的明文 HTTP 配置，只允许 HTTPS
  • 修改 PlatformConfig.kt 中的 API 地址为实际域名
  • 使用强密码替换默认的 admin123
  • 配置 SSL 证书（参考 scripts/init-ssl.sh）
