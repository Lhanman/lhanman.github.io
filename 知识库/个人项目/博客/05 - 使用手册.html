快速开始

启动系统

# 推荐方式
./start-dev.sh

# 手动方式
brew services start postgresql@15
./gradlew :backend:run &

访问地址

  • Android 应用：在模拟器或真机上打开
  • Web 应用：http://localhost:8080（开发模式）
  • 后端 API：http://localhost:8080/api/v1

登录

默认管理员账号：

邮箱: admin@example.com
密码: admin123

首次登录后请立即修改密码！

系统管理

查看系统状态

./status.sh

显示：PostgreSQL 状态、后端服务状态、API 响应、数据库统计、Android 应用状态。

启动 / 停止服务

./start-dev.sh    # 启动开发环境
./stop-dev.sh     # 停止开发环境
tail -f /tmp/backend.log  # 查看后端日志

数据库管理

./db-manager.sh

菜单功能：

  1. 查看数据库状态
  2. 查看所有文章
  3. 查看所有用户
  4. 查看所有标签
  5. 创建测试数据
  6. 清空所有数据
  7. 备份数据库
  8. 恢复数据库
  9. 连接数据库 (psql)

内容管理

创建文章（通过 API）

TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"admin123"}' \
  | grep -o '"token":"[^"]*"' | cut -d'"' -f4)

curl -X POST http://localhost:8080/api/v1/admin/posts \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "title": "我的第一篇文章",
    "slug": "my-first-post",
    "summary": "文章摘要",
    "content": "# 标题\n\n文章内容...",
    "published": true
  }'

Markdown 支持

文章内容支持完整 Markdown 语法：标题、粗体、斜体、列表、链接、图片、代码块、引用、表格等。

用户管理

修改用户角色

curl -X PUT http://localhost:8080/api/v1/admin/users/{id}/role \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"role": "ADMIN"}'

通过 SQL 直接提升权限

UPDATE users SET role = 'ADMIN' WHERE email = 'user@example.com';

  • Xcode（iOS/macOS 开发，仅 macOS）

生产环境

  • Docker 20+
  • Docker Compose 2+
  • 2GB+ RAM
  • 10GB+ 磁盘空间
