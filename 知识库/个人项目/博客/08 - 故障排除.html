端口被占用

lsof -i :9191
kill -9 <PID>

查看后端日志

tail -f /tmp/backend.log

Android 应用问题

无法连接后端

  1. 确认后端运行：./status.sh
  2. API 地址必须是 http://10.0.2.2:9191（不是 localhost）
  3. 检查 AndroidManifest.xml 是否有 INTERNET 权限
  4. 检查 network_security_config.xml 是否允许明文 HTTP

应用启动崩溃

  • 检查网络权限配置
  • 确认 API 地址正确
  • 确认后端服务运行中

Desktop 应用问题

:composeApp:run 启动后立即退出

先执行：

./gradlew :composeApp:run --stacktrace

Module with the Main dispatcher is missing

这是 Desktop 端缺少 Dispatchers.Main 实现导致的。当前项目已通过 desktopMain 引入 kotlinx-coroutines-swing 修复。

如果后续再次出现，请检查：

  • gradle/libs.versions.toml 是否存在 kotlinx-coroutines-swing
  • frontend/composeApp/build.gradle.kts 的 desktopMain 是否引入该依赖
  • ViewModel 是否通过 viewModelScope 在 Desktop 端启动协程

Windows 安装包打包失败

  • packageExe / packageMsi 建议在 Windows 环境中执行
  • 如果在 macOS 上开发，优先使用 :composeApp:run 或 :composeApp:packageDmg

数据库连接失败

用户不存在

/opt/homebrew/opt/postgresql@15/bin/psql postgres -c \
  "CREATE USER postgres WITH SUPERUSER PASSWORD 'postgres';"

确认数据库名

数据库名应为 personalblog。

API 错误

401 Unauthorized

原因解决方案
Token 过期重新登录
Token 格式错误确认 header 格式：Bearer <token>
权限不足确认用户角色是否为 ADMIN

通过 SQL 手动提升权限：

UPDATE users SET role = 'ADMIN' WHERE email = 'admin@example.com';

500 Internal Server Error

  1. 查看后端日志：tail -f /tmp/backend.log
  2. 检查数据库表结构是否正确
  3. 检查请求体 JSON 格式

编译问题

Yarn Lock 冲突

./gradlew kotlinUpgradeYarnLock

macOS/iOS 依赖下载失败

./gradlew :backend:build :composeApp:wasmJsBrowserDistribution

inline 函数编译错误

inline 函数不能访问 private / internal 属性，改为 public。

expect/actual 注解不匹配

expect 和 actual 函数的注解必须完全一致，包括 @Composable。
