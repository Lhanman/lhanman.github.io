盘前简报安装指南

装好之后，每个 A 股交易日早上，Mac mini 会自己生成一份盘前简报，发到你手机的 Telegram 上。A 股休市的日子什么也不发。一共三步，前两步在手机和浏览器上点几下，第三步复制几条命令。

北京时间08:30
=
这台 Mac（东京时间）09:30
① 建机器人 ② 填 .env ③ 装定时任务 平时怎么查 卸载 注意事项
1

在 Telegram 里建一个机器人

在手机上做，大约 3 分钟

  1. 在 Telegram 里搜索 @BotFather（带蓝色认证标记的那个），点进去，发： 
    /newbot
  2. 它先问机器人的显示名字，随便起，比如"盘前简报"。
  3. 再问用户名，必须以 bot 结尾，而且全网不能重名，比如 lhan_brief_bot。
  4. 建好后它会回一段话，里面有一串形如 1234567890:AAH… 的字符，这就是机器人密钥。
    密钥相当于这个机器人的钥匙：不要发给别人，也不要截图外传。
  5. 搜索你刚起的用户名，点进去，点"开始"（Start），再随便发一句话，比如"你好"。
    这一步不能省。机器人不能主动找一个从没跟它说过话的人。
2

拿到聊天编号，填进 .env

浏览器加终端，大约 2 分钟

  1. 在浏览器里打开下面这个网址。复制后先把 <密钥> 换成上一步拿到的整串密钥： 
    https://api.telegram.org/bot<密钥>/getUpdates
  2. 页面上找 "chat":{"id": 后面的那串数字（一般 9 到 10 位），这就是你的聊天编号。页面上什么都没有的话，回 Telegram 再给机器人发一句话，然后刷新。
  3. 在 Mac 的终端里复制一份模板，并打开它： 
    cd ~/workbench/ashare-quant
cp .env.example .env
open -e .env
  4. 在打开的文件里填上这两项（换成你自己的值），保存：
    .env 的样子
    AQ_TELEGRAM_BOT_TOKEN=1234567890:AAH...
AQ_TELEGRAM_CHAT_ID=987654321

    .env 不会进 git，放心填。

  5. 手动试发一次，确认手机能收到： 
    uv run aq brief --push

    休市日它只会提示"A 股休市，不生成简报"。想在休市日也试试发送，就补看一个以前的交易日：

    uv run aq brief --date 2026-09-24 --push
3

装定时任务

终端里复制两段命令

  1. 装上： 
    cd ~/workbench/ashare-quant
mkdir -p data/logs
cp deploy/launchd/com.ashare-quant.brief.plist.example ~/Library/LaunchAgents/com.ashare-quant.brief.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.ashare-quant.brief.plist
  2. 马上手动触发一次，确认整条链路是通的： 
    launchctl kickstart -k gui/$(id -u)/com.ashare-quant.brief

    交易日手机会收到简报；休市日不会收到消息，但日志里会有一条"A 股休市，不生成简报"。

平时怎么查

看日志

每次运行开头有一行"aq brief --push 开始"，后面是简报正文和"已推送"，或者失败原因。

cd ~/workbench/ashare-quant
tail -n 60 data/logs/brief.log

看历史简报

每份简报都存在 data/briefs/<日期>-<时间戳>/：brief.txt 是发出去的原文，brief.json 记着每一项的数字、用的是美东哪一天、有没有推送成功。

ls -t ~/workbench/ashare-quant/data/briefs | head

看定时任务在不在

launchctl print gui/$(id -u)/com.ashare-quant.brief | head -20

卸载

卸载只是不再定时运行，已经存下的简报和数据都不动。

launchctl bootout gui/$(id -u)/com.ashare-quant.brief
rm ~/Library/LaunchAgents/com.ashare-quant.brief.plist

注意事项

时区换算
这台 Mac 的时区是东京，比北京快 1 小时。模板里写的 09:30 就是北京时间 08:30。以后要改运行时间，在北京时间上加 1 小时再填。
代理要开着
Telegram 在国内要经 Clash Verge（127.0.0.1:7890）才能连上。Clash Verge 没开或者端口改了，简报就发不出去，日志里会写"Telegram 发送失败"。端口改了要同步改模板并重装。
Mac 不能关机，要保持登录
这个任务跟着你的用户账号运行，关机或退出登录就不会跑。机器睡着时错过的那次，唤醒后会补跑一次。
改了模板要重装
改完 ~/Library/LaunchAgents/com.ashare-quant.brief.plist 之后，先执行"卸载"里的第一条，再执行第 3 步里 launchctl bootstrap 那一条。
收不到消息
先看日志。常见原因：密钥填错（日志写"机器人密钥无效"）、聊天编号填错（"找不到这个聊天编号"）、代理没开、还没给机器人发过消息。
来源：仓库里的 deploy/launchd/安装说明.md。这是 M7 常驻程序上线之前的临时做法，用的是 macOS 自带的 launchd。
