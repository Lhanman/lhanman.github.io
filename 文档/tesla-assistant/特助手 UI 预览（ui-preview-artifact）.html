特助手 UI 预览

iOS 用液态玻璃，Android 用毛玻璃，同一套信息结构。车是主角，状态芯片直接浮在车上，控制用玻璃磁贴和刻度滑块，轻点即执行。页面里的车名、数值、行程、日志都是编造的示例数据。

车是主角　首页上半屏就是你的车，在线、电量、"左后车窗未关"这些状态是飘在车周围的玻璃芯片，下面一块玻璃面板收着电量刻度和各项状态。

车图的来源　车图只在手机运行时从特斯拉官网的出图服务加载并缓存本机，不进仓库、不进公开站点；加载失败自动退回平面图。接口读不到车漆颜色，需要你选一次。

少一点按钮　锁车、闪灯、鸣笛是玻璃磁贴，轻点就做，结果写在磁贴上；空调和充电上限是刻度滑块；场景是顶部一排玻璃胶囊。没有满宽实心按钮，也没有成排的"执行"。
