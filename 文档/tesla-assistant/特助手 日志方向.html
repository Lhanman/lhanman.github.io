日志：三套做法

现在的日志页还是一块圆角玻璃卡片，右侧结果是彩色字，和首页不是一套语言。下面三套都换成首页的写法：整宽行、细线、左侧标签列、窄体数字、方角；失败整行红底反白并写明「失败」；被拒绝写字不变色；演练（只走流程没真发）盖上和休眠一样的斜影线。三套的数据相同，按钮同步切换。

A　流水

日志我的 Model 3
每条控车都会记录，包含被拒绝的。

最朴素的一版。按天分组，日期行右边写条数和失败数；每条的时刻放在首页那样的左侧标签列，中间是指令名和操作人（两行，不用「·」），右边是总耗时。一眼能看出谁、什么时候、成没成、花了多久。

B　耗时尺

日志我的 Model 3
每条控车都会记录，包含被拒绝的。

把详情页的「长度对比」提到列表上。顶上一行汇总（共几条、失败几条、一般要几秒），像首页的「今日」行；每条下面一根细条，所有条共用 0–15 秒的同一把尺，慢的那条自然长出来。没耗时数据的旧记录和演练画虚线，不画条。

C　纸带

日志我的 Model 3
每条控车都会记录，包含被拒绝的。

借行车记录仪的纸带。每天一条 0–24 点的纸带，每次控车是一根竖线：失败是红色长线，被拒绝是短线，演练是空心线，一天什么时候在用车一目了然。下面是对齐成四列的账目，更紧凑，一屏能看十多条。

详情（三套共用）

保留你选过的 L3 长度对比，只改头部：原来「07:41 · 小明 · 失败」挤在一行，改成时间、操作人、结果三个读数（小标签在上），失败的结果红底反白。下面切到「全部成功」可以看成功时的样子。

我的推荐：B 耗时尺。
  1. 你在详情页选了长度对比，B 让列表和详情是同一把尺，点进去只是把一根条拆成几段，前后连得上。
  2. 日志最常回答的两个问题是「刚才那条成没成」和「为什么这么慢」，B 的红底行和长条正好对应这两件事。
  3. 顶上的汇总和首页的「今日」行同构，切 tab 时两页像一套东西。

A 更省事、更安静；C 最有辨识度，但纸带在条目少、集中在一两个时段时会很空。三套都共用：骨架屏用同样的行结构，加载失败、没有记录、只读账号这些状态照旧，读屏把一条读成「08:12，打开空调，小明，成功，3.2 秒」。
